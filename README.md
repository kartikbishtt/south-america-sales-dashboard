# South America Sales Dashboard — 2022

An interactive Microsoft Excel dashboard analyzing sales performance across South American markets in 2022.

## Project Overview

This project focuses on transforming sales data into an interactive dashboard for business performance analysis.

The dashboard provides a high-level view of:

- Sales performance
- Profit
- Customer metrics
- Monthly sales trends
- Sales by country
- Customer satisfaction

## Dashboard Preview

![South America Sales Dashboard](screenshots/dashboard.png)

## Key Analysis

### Sales Performance
Analyzed monthly sales performance and compared results across 2021 and 2022.

### Geographic Performance
Compared sales across South American countries to identify differences in market performance.

### Customer Satisfaction
Visualized customer satisfaction across key service dimensions including:

- Speed
- Quality
- Hygiene
- Service
- Availability

### KPI Analysis
Created dashboard KPIs to provide a quick overview of overall business performance.
